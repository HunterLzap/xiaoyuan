```python
def _is_end_intent(text: str) -> bool:
    """判断是否为结束意图"""
    text_lower = text.lower().strip()
    end_keywords = [
        # 明确的停止指令
        "闭嘴", "住嘴", "别说了", "不说了", "停下", "stop",
        # 关机/退出类
        "关机", "退下", "下去吧", "退出",
        # 结束对话类
        "不聊了", "不想聊", "结束", "挂了", "拜拜", "再见",
        # 否定 + 需要/想要
        "不需要", "不想要", "不用"
    ]
    return any(kw in text_lower for kw in end_keywords)
```

#### 3.2 Write 方法（缓存播放 PCM）

**文件**：`main/audio/codecs/es8311_audio_codec.cc`

**改动位置**：Line 238-256

**改动内容**：
```cpp
int Es8311AudioCodec::Write(const int16_t* data, int samples) {
    if (output_enabled_) {
        ESP_ERROR_CHECK_WITHOUT_ABORT(esp_codec_dev_write(dev_, (void*)data, samples * sizeof(int16_t)));

        // 如果启用软件回采，缓存播放数据
        if (input_reference_ && input_enabled_) {
            // 检查缓冲溢出（参考 BoxLite line 257-261）
            if (write_pos_ - read_pos_ + samples > (int)ref_buffer_.size()) {
                // 写溢出，只保留最近的数据
                read_pos_ = write_pos_ + samples - ref_buffer_.size();
            }

            // 移动数据到缓冲区头部（避免循环写越界）
            if (read_pos_ > 0) {
                if (write_pos_ != read_pos_) {
                    memmove(ref_buffer_.data(), ref_buffer_.data() + read_pos_, 
                            (write_pos_ - read_pos_) * sizeof(int16_t));
                }
                write_pos_ -= read_pos_;
                read_pos_ = 0;
            }

            // 拷贝播放数据到缓冲
            memcpy(&ref_buffer_[write_pos_], data, samples * sizeof(int16_t));
            write_pos_ += samples;
        }
    }
    return samples;
}
```

**逻辑**：
1. 正常播放 PCM 到扬声器
2. 同时缓存到 `ref_buffer_`（环形缓冲）
3. 溢出时保留最近数据，丢弃旧数据

#### 3.3 Read 方法（交织麦克风 + 参考）

**文件**：`main/audio/codecs/es8311_audio_codec.cc`

**改动位置**：Line 197-227

**改动内容**：
```cpp
int Es8311AudioCodec::Read(int16_t* dest, int samples) {
    if (input_enabled_) {
        if (!input_reference_) {
            // 单声道模式：直接读麦克风
            ESP_ERROR_CHECK_WITHOUT_ABORT(esp_codec_dev_read(dev_, (void*)dest, samples * sizeof(int16_t)));
        } else {
            // 双声道模式（麦克风 + 软件回采参考）
            int size = samples / input_channels_;  // 实际麦克风样本数
            std::vector<int16_t> mic_data(size);

            // 读麦克风单声道数据
            ESP_ERROR_CHECK_WITHOUT_ABORT(esp_codec_dev_read(dev_, (void*)mic_data.data(), size * sizeof(int16_t)));

            // 交织：dest[0]=mic, dest[1]=ref, dest[2]=mic, dest[3]=ref, ...
            int j = 0;
            int i = 0;
            while (i < samples) {
                dest[i++] = mic_data[j++];  // 麦克风通道
                dest[i++] = ref_buffer_[read_pos_];  // 播放参考通道
                read_pos_ = (read_pos_ + 1) % ref_buffer_.size();
            }

            // 清空缓冲（避免累积）
            if (read_pos_ == write_pos_) {
                read_pos_ = write_pos_ = 0;
            }
        }
    }
    return samples;
}
```

**数据格式**：
- 输入：麦克风单声道 PCM
- 输出：交织双声道 PCM（L=麦克风，R=播放参考）
- ESP-SR AFE 接收格式："MR"（Mic + Reference）

## 三、遇到的问题与解决

### 问题 1：UI 动画帧全部丢失（黑屏）

**现象**：
- 设备刷机后黑屏
- 串口日志显示：
  ```
  W (47849) AtomS3R+EchoBase: missing frame idle-00.png
  W (47849) AtomS3R+EchoBase: missing frame idle-01.png
  ...
  I (47919) AtomS3R+EchoBase: loaded 0/16 idle frames
  ```

**原因**：
- 编译时使用了 `-DTAFEI_MN5_SMALL_FONT=ON` 参数
- 生成的 `generated_assets.bin` 没有包含 UI 动画帧（idle/listen/think/speak）

**解决方案**：
1. 去掉 `-DTAFEI_MN5_SMALL_FONT=ON` 参数
2. 重新编译
3. 仅刷固件（保留设备上现有的 assets）

### 问题 2：assets 分区溢出

**现象**：
```
A fatal error occurred: File build-tafei-mn5-ui-anim\generated_assets.bin (length 3099664) 
at offset 5767168 will not fit in 8388608 bytes of flash.
```

**原因**：
- `generated_assets.bin` 大小 3MB
- assets 分区从 `0x580000` 开始，只有 2.5MB 空间

**解决方案**：
- 只刷固件（`0x20000 xiaozhi.bin`），跳过 assets
- 设备使用之前刷入的 assets（功能正常）

### 问题 3：编译环境找不到 idf.py

**现象**：
```
idf.py : 无法将"idf.py"项识别为 cmdlet、函数、脚本文件或可运行程序的名称
```

**原因**：
- 未设置 `IDF_TOOLS_PATH` 和 `IDF_PATH`
- Python 环境不正确

**解决方案**：
使用 `build-mn5.ps1` 脚本，它会自动设置所有环境变量：
```powershell
$env:IDF_TOOLS_PATH = 'E:\xiaodan\firmware\.espressif'
$env:IDF_PATH = 'E:\xiaodan\firmware\esp-idf-v5.5.2'
# ... 然后调用 idf_tools.py export 导入工具链到 PATH
```

### 4.2 AEC 调参（如果效果不佳）

**调整位置**：`main/audio/codecs/es8311_audio_codec.cc` Line 217 附近

**调整参数**：延迟补偿（读取位置偏移）
```cpp
// 当前代码（Line 217）
read_pos_ = (read_pos_ + 1) % ref_buffer_.size();

// 调参方案：增加延迟补偿
const int DELAY_SAMPLES = 400;  // 从 0 开始，每次增加 100（6.25ms）
read_pos_ = (read_pos_ + DELAY_SAMPLES) % ref_buffer_.size();
```

**调参步骤**：
1. 从 `DELAY_SAMPLES = 0` 开始
2. 每次增加 100 samples（6.25ms @ 16kHz）
3. 测试播放中说话的识别准确率
4. 找到最优值（估计在 400-800，即 25-50ms）

**原理**：
- 播放 PCM 到扬声器有硬件延迟
- 声音从扬声器到麦克风有传播延迟
- 需要调整参考信号的时间对齐

### 4.3 已知限制

1. **单麦 AEC 效果有限**
   - 理论抑制：20-30dB
   - 对比：双麦/多麦阵列可达 40-50dB
   - 强回声场景可能效果不佳

2. **时间对齐依赖调参**
   - 硬件延迟因设备而异
   - 需要真机测试找最优值

3. **缓冲溢出风险**
   - 长时间连续播放可能出现缓冲管理 bug
   - 监控 `write_pos_` 和 `read_pos_` 差值
