# 视觉方向与信息架构

更新：2026-11-25。沿用已确认的 Codex 灰阶明暗工作区（`current-codex-grayscale`）与暖琥珀金强调色；不换前端框架或另起一套品牌配色。

产品范围见 [PRD](../docs/prd.md)，当前生效状态见 [START](../START.md)。

## 信息架构（单助手工作台）

| 导航区 | 页面职责与结构 | 关键设计约束 |
| --- | --- | --- |
| 对话工作台 | 左侧「最近对话」会话列表，主区聊天流 + SSE 步骤胶囊 + 交互式确认卡片 + 实时停止按钮 | 回复详情只展示**等待耗时**、模型/来源与 Token 明细，移除估算费用与多余底部解释 |
| 设置 → 模型 | 精简为「日常对话与语音」「电脑操控模型（内置视觉预设 + `测试` 按钮）」两张卡片 | 折叠「高级设置」仅保留 3 项可调项（`人声灵敏度阈值`、`按需发工具`、`工具等待播报首响`） |
| 设置 → 人设与声音 | 单助手人设提示词、`agent_profile`、百炼复刻音色管理与语速/音调 | 参数与按钮保持清晰平直对齐，不恢复 920×720 旧三页签弹窗 |
| 设置 → 能力与知识 | 统一单开关同步启用与选入（「联网搜索」精简为开关+`测试` 按钮、M5 资料、`个人电脑操控`、自定义 API）；多独立知识库左库右文档 | 独立「天气查询」卡片与默认城市配置已移除，联网卡片统一承担联网与天气搜索 |
| 设置 → 设备 | 「电脑」与「硬件」两页签；公网「电脑」页优先显示在线/离线电脑卡片，「接入新电脑」2 步复制指令默认折叠且令牌不带尖括号 | 公网模式不暴露配对令牌与截屏预览；保留 AtomS3R 实机参数读回区分 |
| 记录（4 页签） | **对话历史 / 知识库 / 工具调用 / 异常** | 对话历史列表 1:1 对齐侧栏会话，详情采用**左树右详「Agent 执行轨迹」分栏**；知识库仅展示纯检索（`kb_only=true`） |

## 视觉约束

- 使用项目既有浅色米灰/深色炭黑灰阶表面色与暖琥珀金高亮，不套用外站紫色渐变或花哨装饰。
- 表单标签列对齐，清理冗长解释型 `<p>` 说明，保留必要的动作按钮与通断徽章。
- 设备 128×128 小屏维持原有简洁状态与短文字/表情呈现；工作树新动画实验不直接视为线上界面。

组件见 [components](components.md)，布局见 [layout](layout.md)，变量见 [tokens](tokens.md)，资产见 [assets](assets.md)，命名见 [naming](naming.md)。
