# 组件与交互规范

更新：2026-11-15。原生DOM与既有CSS/JS渲染函数继续复用，不新增框架。本文规定交互；实际运行/检查结果只在progress，当前版本只在START。

## 设置与能力归属

设置采用整页两栏，左导航、右内容，窄屏单列并保持可达；不恢复920×720居中弹窗或旧三页签。

- **助手配置**集中提示词、选API能力、选多个知识库及已有声音设置；单助手，不加Agent总开关。提示词/能力/库选择绑定已有实现，不再列为待开发。
- **资源管理**统一天气、M5官方资料、自定义API；资源“启用/停用”与助手“选入/未选”分开，空选择不默认为全开放。个人资料检索不再作为重复总开关。
- **知识库**左侧库列表、右侧文档表；上传、状态、正文/片段、下载、替换、标签、删除和分页按现有接口。多库及原资料迁移已实现，不按单库分组重做。
- **模型接入**实时/分模型分别配置，同服务引用一份服务端凭据；列表/草稿调用/保存独立，不试遍模型。密钥留空保留原值，换实际服务地址需重新输入对应密钥。
- **声音**保留塔菲与现有参数；设备音量保存与应用分开，离线不称已生效。试听只使用相应已保存连接和声音草稿，取消/改稿/离页回收播放资源，不保证供应商停止计费。

保存失败保留输入，成功不清空历史或另一模式配置。未保存草稿不能污染实际调用；导航和旧hash兼容以现行代码为准，不复制过期分类顺序。

## API工作台

左列表、右配置，复用可视化/JSON、Params/Headers/鉴权/Body、输入/输出定义、测试与保存。两种编辑方式共享同一份定义；无法无损转换时明确说明，不能静默丢字段。

测试是真实请求，不暗中保存或启用；查询按已开放权限发送，修改/删除/付费按具体动作确认。保存本身不发送外部请求，不隐式扩大助手选用范围。内置能力只展示适用配置，不伪造URL。

显示实际HTTP、业务结果、错误和耗时；未知字段写未提供，不补造成功。输出定义不伪造上游未返回值，已有密钥不回显。

## 对话、用量与依据

普通聊天直接答，需要工具/资料时按真实状态呈现，详细调用进既有洞察；不展示模型内部思维或每轮固定流程。

- 消息脚注区分输入/输出/合计，详情按供应商提供展示文字/音频/缓存及逐响应数值；缺项不补0，多次响应与本轮汇总分开。数值不是输出字数或最终账单。
- 出处关联实际工具、片段和文档版本；召回、送入模型与最终引用分开。没有依据如实说未找到，不能把检索分数称为准确率。
- 生成结束与播放结束分开，取消/被打断/未播出如实显示。用户打开旧历史不代表设备续聊该段。
- Enter发送、Shift+Enter换行，中文输入法组合不误发；模型/外部资料按不可信文本渲染，不直接执行HTML或代码。
- 已移除的“Windows·本机服务”文案不恢复；不增加模型/实现细节到普通用户流程。

## 网页语音与设备状态

网页沉浸式语音界面保留真实采集、生成、播放、等待与失败状态；状态球不以装饰替代麦克风/播放事件。退出、停止和切换时取消当前活动，旧轮次不回灌；语音文字写回同一会话历史，不长期保存录音供回听。

设备页区分保存、发送、回执、读回与实际效果。画面是128×128设备端独立设计，不把网页DOM规范当固件资源。当前新动画不接入稳定链，具体暂停见START。

## 洞察、删除与可访问性

知识库/API记录分开筛选和分页，详情按需读正文与调用。回溯保持当时快照，资料替换/删除后说明原文状态；手动调试不伪造为模型自动调用。

审计单条/按筛选删除须说明范围与数量；清空无筛选不放行，数量变化要求刷新后确认；只删审计，不连带删知识库、配置或聊天。已有 `confirm` / `expected_total`一致性规则保留。

复用有label、焦点和禁用状态的原生控件，错误就地持续显示；长地址/模型名可换行，代码独立滚动，不撑破页面。涉及界面改动时按实际影响检查桌面/窄屏与明暗主题，不把历史截图或本次文档审计当页面实跑。
