# 视觉与音频资源规范

## 当前资产

- 网页图标为 `backend/app/app.html` 内联SVG symbol，主题颜色来自CSS。没有要求新增位图、外部图标库或品牌包。
- 本地语音模型、LICENSE、tokens、lexicon、espeak等配套资源都属于运行资源，不属于网页static目录；保持现有目录。
- 已有三个Kokoro WAV及配套JSON在 `output/speech/`，既有检查截图也在项目内输出或缓存位置；不把带私人信息的截图嵌入公共文档。
- 已有塔菲复刻音色、唤醒资源及旧像素素材须保留；新动画原图/源码/构建产物作为实验保留，不因资源存在自动接入或刷写。当前实际配置与暂停事项以START为准。
- 三张参考截图（助手 Skill 页、API 管理页、文档知识库页）仅作**信息架构参考**，不导入为产品资产，也不复制其品牌、图标与文案。

## 新增资源的要求

1. 记录用途、来源、许可证、适配尺寸/格式和实际验证，不以“网上可下载”当作可使用授权。
2. 优先复用已有SVG；确需图片时保持项目内受控路径，名称见naming。未使用的候选不下载，不生成多个重复版本。
3. 设备图片与表情需按当前固件资源机制及128×128屏幕核对，不能将图片放入网页就宣称设备已支持。
4. TTS音色标签要包含来源，避免混淆Kokoro、edge-tts和小智预设；试听标明文本、语速、格式与耗时。
5. 原始用户录音、聊天导出、接入地址和控制台截图可能含隐私，不能进入示例、公开资产或Git。
6. 聊天内容仅长期保留文字，原始和合成音频只作必要处理/播放缓存，按实际生命周期释放，不进入普通日志或长期备份。已有清理实现不等于全部异常场景已确认，实际证据看progress；原音色录音样本与非私人试听按既有用途保留。

Windows下载、安装临时文件、模型、缓存和输出均留在 `E:\xiaodan`；遵守 [操作手册](../docs/operations.md) 的显式环境变量约束。云端已部署但不因此授权任意新资产下载或上传，本轮只改文档。
