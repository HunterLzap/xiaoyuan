# 组件与交互规范

当前为原生DOM组件，不要求新增React、组件库或构建工具。复用已有CSS类和JS渲染函数，再考虑提取。

## 单助手信息架构（2026-11-08 规划·未实现）

统一目标：一个硬件语音助手，正常聊天＋按需调 API／知识库，简单、高效、快速；不做多助手或复杂 Agent 平台。分三层，界面归属如下。**除标注“已实现”外均为设计目标，未实现，不写成已可用。**

### 资源层（全局可用状态）
- **API 能力管理**：天气 / M5 官方资料 / 自定义 API 收敛为**同一列表**（左列表＋右配置，参照图2）。去掉“个人资料检索”独立工具项（改由助手选入知识库驱动）。外部 API 保存后回列表，用**列表开关**启停，取消工作台底部“保存后启用”勾选框。状态＝启用／停用。
- **知识库管理**：**多独立库**（左库列表＋右文档表，参照图3），文档含同步/索引状态、预览、重新上传、标签、删除，沿用分页；检索按**选中库服务端硬过滤**。现状为**单库按分组（已实现）**；多库**未实现**，旧资料需迁移默认库。

### 助手层（使用范围，未实现）
- **一个助手**集中配置＝提示词＋「API 能力」多选＋「知识库」多选，复用现有「角色与声音」页扩展；不新建顶层页、不加 Agent 总开关、不做多助手。
- 选中态用「**选入本助手／未选**」；资源「启用／停用」是全局状态，助手只引用、不重复配置。
- 现状：工具是全局开关，无“提示词＋选择”绑定（**本期主要缺口**）。

### 对话层
- 查询类自动调用；写／付费类“提操作→确认→执行→回报”（**未实现**，因 AEC 限制确认走“下一轮说确认”）。
- 调用结果展示已有但折叠（`renderMessageReferences` 的“调用了 N 次工具／已提供 N 段资料”）；目标改为回答下方**一行可见**、可点开出处（折叠已实现，常显未实现）。

### 与旧规范的关系
本节“资源层／助手层／对话层”与统一命名（资源启用/停用、助手选入/未选）**取代**下文任何把“能力管理＝官方资料/个人知识库/外部工具”“工具全局开关”当最终形态的旧表述；已实现细节仍以下文为准。

## 设置整合（2026-11-07）

API 接入采用实时对话／分模型两个模式分页。实时页仅显示实时连接、模型和音色；分模型页显示文字连接、文字模型、本地识别和声音模型／音色。两个模式下共用能力始终位于同一位置，不在页内重复文字服务。实时模式文字和语音共用实时模型，界面模型提示必须显示实际使用的模型。

角色页只管理提示词、设备音量、语速、音调和草稿试听。语速和音调应用到网页与设备共用的实时输出，默认值不额外启动音频处理。音量旁提供单独的应用按钮并显示真实结果，离线只能保存，不声称设备已生效。保存设置不清空历史和另一模式的已保存连接。

## 沉浸式网页语音（2026-10-31）

点击聊天输入区的麦克风后，进入独立全屏语音界面；后台侧栏、会话列表和文字输入暂时不可交互。中心状态球分别表达麦克风开启、收音、识别/生成、播放、停止和失败；只使用真实状态驱动动画，不把静态装饰当作录音反馈。当前阶段仍是“开始录音→结束并发送→识别→回答”，不表示为持续免按键对话或语音打断已经可用。

当前问答以字幕显示在状态球下方；底部主按钮控制开始/结束录音，回答进行中提供停止回答，键盘按钮返回文字输入，关闭按钮结束语音模式并回到当前会话。语音问答继续写入同一会话和SQLite，退出后可在聊天历史中查看、重播和停止。桌面与390px、明暗主题都必须无横向溢出，并支持Escape退出及减少动态效果偏好。

## 统一聊天输入（2026-10-24）

默认一个文字输入框，底部保留资料开关、麦克风与发送；麦克风作为进入沉浸式语音界面的入口。语音界面沿用录音回合，不改变识别、模型、TTS或历史协议。

语音识别的提问和回答使用与文字聊天相同的用户消息/助理消息节点。回答随流式文字更新，重播与停止回答放在该条助理消息底部；失败原因保留在该消息内。播放中的停止只结束当前本地播放和请求，迟到内容不更新对话。录音、识别、思考、生成、播放等状态放在输入区一行内，不另占长期面板。

生成结束与播放结束分开；TTS部分失败保留文字并说明语音未完成。1365/390px、明暗主题下语音界面无横向溢出。语音问答与文字共用当前会话和SQLite，不再使用网页临时上下文。

| 现有元素 | 用途 | 必须有的状态/规则 |
| --- | --- | --- |
| `.nav-button` / `.session-item` | 导航、会话切换 | 当前选中、空列表、加载与加载失败 |
| `.icon-button` | 工具栏操作 | aria-label或明确名称，键盘焦点，禁用条件 |
| 设置表单/`.settings-row` | 模型、角色与设备设置 | label、说明、校验错误、保存中和结果 |
| `.composer` | 文字输入 | 空输入、提交中、失败保留输入、手动重发 |
| `.notice` | 用户可见反馈 | 状态文字明确，错误持久到用户能理解，不能只闪一下 |
| `.device-result-row` | 设备执行结果 | 保存/发送/回执/读回/人工效果分别表达 |
| 消息与代码块 | 对话历史 | 安全文本渲染、复制、长文本换行和代码滚动 |

API接入默认一个公共地址/密钥；“语音使用不同服务”控制独立字段的展开与禁用。公共模式不向浏览器取回/复制旧密钥，旧独立配置保留；日常页不显示密钥。

## 设置页（整页两栏，2026-11-07）

设置不再使用弹窗。点击「设置」进入 `/settings` 整页两栏：左列分组功能导航＋搜索，右列对应内容区独立滚动，底部保留取消/保存。去掉 `settings-dialog` 弹窗；删除会话、克隆、发送确认等小确认框仍用原生 dialog。API 配置工作台也改为整页视图（从「能力管理」或左栏进入），不再弹窗套弹窗，关闭回设置。

左列按现有功能分四组，一个不丢：
- 助手：助手配置（提示词＋选 API 能力＋选知识库，复用原“角色与声音”页）、API 接入
- 能力：能力管理（「工具／知识库」两选项卡；工具＝API 能力，知识库＝资料）、API 配置工作台
- 设备：设备连接
- 数据：数据洞察

当前项高亮并带 `aria-current="page"`；搜索按名称过滤导航（如搜“设备”只剩“设备连接”）。默认进入第一项「角色与声音」（`/settings` 无哈希时）；用户访问过的分类记在本地 `atoms3r.settingsSection`，下次点设置回到上次分类（`#api`→API 接入、`#role`→角色与声音、`#capabilities`→能力管理、`#insights`→数据洞察）。

### 布局与响应式
- 桌面 1365：两栏 `flex`，左栏固定约 264px，右栏独立滚动；无横向溢出、0 JS 错误。
- 390 窄屏：左列折成顶部可滚动导航（约 390×371），右栏单列 390px 铺满；明暗主题均无横向溢出。
- Esc 关设置回聊天；有 dialog 打开时 Esc 优先交给 dialog，不误关工作台。

### 保存与状态
- 各页保留现有字段、校验、保存/取消、切页保留草稿、试听、接口调用与空/加载/错误状态；会话内切换分类不丢未保存草稿。
- 「API 接入」底部为「保存并关闭」：不改值直接保存也走真实 `PUT /api/settings/api` 并回读，成功提示「配置已保存。」后关闭窗口回对话。“角色与声音”“设备”等页各有独立保存与结果提示。
- 空密钥字段不提交，保存不会清空已保存密钥。
- API 接入与日常（角色/声音）分别为独立表单：接入只改连接，日常只改角色/模型/声音；已保存服务的模型列表自动加载，手填 ID 折叠为备用；测试/试听只读已保存连接，不用未保存密钥。

## 数据洞察（2026-11-07）

数据洞察页分「📖 知识库记录」「🔌 API记录」两个选项卡（`role=tablist`，当前项高亮、方向键切换），一次只显示一张表，各自保留分页；从任一选项卡进入「详情」再返回，回到原选项卡。标题带图标；解释性说明收进标题旁 ⓘ 悬停提示，行内不再堆叠小字，正文靠留白与布局引导操作。

### 搜索与筛选
- 知识库：关键词（问题/答案）、回答类型、起止日期；API：关键词（工具/请求摘要）、状态、工具名、起止日期。均带「重置」，右侧显示「共 N 条」。
- 搜索输入防抖；连续修改取消上一请求并用 `requestId` 丢弃迟到结果，避免旧条件覆盖新条件；中文输入法组合期不触发。
- 日期控件取本地整日起止并转 UTC ISO 传给后端，与表格展示的本地时间口径一致。
- 筛选接后端查询参数 `q / answer_type / status / tool_name / since / until`，`total` 为过滤后数量；无匹配显示「没有匹配的记录，试试调整搜索或筛选条件。」，与「尚无记录」区分。

### 表格与长文本
- 时间、状态、耗时、操作列保持紧凑单行；问题、答案、工具名、请求摘要默认单行省略。
- 悬停或键盘聚焦时显示可换行、可选中文字的完整提示框（纯文本、用已脱敏的展示内容，不额外请求）；移动端无悬停，靠「详情」查看完整内容。
- 桌面按容器宽度分配列宽，约 1120px 窗口下「详情」「删除」直接可见、无横向溢出；≤820 仅在表格内部横向滚动，页面本身不横向溢出。

### 删除（方案 A）
- 行内删除 ＋「清空筛选结果」；两者都走带遮罩的确认框，显示「将删除 N 条」和删除范围（单条摘要或当前筛选条件）。无有效筛选时「清空筛选结果」禁用。
- 清空前先按当前筛选重取匹配 `total`，提交携带 `confirm: true` 与 `expected_total`；服务端无筛选拒绝（422 `filter_required`）、缺确认拒绝（422 `confirm_required`）、数量变化返回 409 `count_changed`（提示刷新后重新确认）。
- 删除只清审计记录与详情，不动知识库原文、工具配置和聊天历史；成功后刷新当前页并提示「已删除 N 条」；失败或 409 弹出可操作原因、不伪报成功。
- 删除是写操作，统一 `request()` 已带 `X-Local-Settings: 1`，避免写保护中间件 403。

## 通用约定

- 每个任务区域有明确主操作；“测试连接”“保存配置”“应用设备设置”承担不同动作，不合并成误导按钮。
- 设置分类用原生按钮，当前页有选中样式和aria-current；角色与声音同一次保存，音色字段按模型切换；高级区用带箭头的details。错误显示具体原因。
- 草稿试听用原生audio控件，点击后播放；改草稿/文本、离开语音页或保存时停止旧音频、回收Blob URL。合成期间可取消浏览器请求/播放，不承诺供应商停止计费。
- API配置页沿用原设置页；“获取模型列表”只获取，不自动选择或试遍模型。原生选择框填入模型ID，手填始终保留；地址、密钥或列表协议改变即移除旧候选，不清空模型ID。错误和空列表在模型区域持续显示；配置编辑后隐藏旧草稿测试结果，避免误认为新草稿已通过。
- 删除会话沿用确认交互；未完成或失败不伪报成功。付费试听/连接测试说明会产生真实请求。
- 每个数据区考虑加载、空、错误、部分成功、离线和无权限状态。设备离线时可以保存偏好，但不能显示已作用到设备。
- Enter发送、Shift+Enter换行，中文输入法组合状态不误发；保留Ctrl+K和Ctrl+Alt+N已有快捷键。
- 模型输出与外部资料按不可信文本处理，不直接执行HTML或工具代码。
- 新增语音状态和音色试听必须能取消/理解失败；试听成功不等于设备播放成功。
- 按PRD区分待机、收音、识别/生成、播放和等待追问；文字已生成不等于实际播完，被打断/未播出不能显示整段已讲完。网页选中旧历史不代表设备正在续聊该段。

设置分类已表达归属时，正文不重复堆叠同名标题、开发阶段说明及同义分组标题；保留实际状态、操作和必要的数据范围说明。资料在握手校验通过前显示未测试，失败就地显示可操作原因，不将入口已启用等同于连接成功。

API 接入页单列自上而下：连接（服务名、地址、密钥、获取方式、语音是否独立）→ 对话模型（下拉含“手动填写”、刷新、测试）。不折叠、不分组，不在界面暴露回复上限、超时、币种与价格（沿用已保存值）。语音使用不同服务时条件展开。常规窗口一屏呈现，极短视口允许必要滚动。**M5 官方资料已归入「API 能力」列表，不再在接入页单独设开关（目标设计）。**

设置页为整页布局（旧 920×720 dialog 已弃用）；表单类页（接入、声音）桌面内容限宽约 700px，能力／知识库等表格式页用满右侧宽度。底栏统一为左状态、中当前模型提示（手机隐藏）、右取消与保存。声音模型与对话模型列表都来自已接入服务 `/models`；对话模型保留“手动填写”兜底；试听只用已保存连接、不读未保存密钥，音频仅存浏览器内存。手机端字段单列，标签在上、控件在下。
