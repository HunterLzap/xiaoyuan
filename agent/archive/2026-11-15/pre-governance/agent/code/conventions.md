# 代码与开发规范

> **当前口径（2026-11-08，统一目标；与下文冲突时以本块为准）**：目标是**一个硬件语音助手**，正常对话 + 按需调 API/知识库，简单、高效、快速；不做多助手系统、长期记忆、重型规划平台。**“Agent”= 工具反馈循环**（模型选工具→拿结果→续答），复用现有链，**不新增每轮规划模型请求**（否则拖慢首声）。
> - **实时音频链不重写**：设备/网页语音走百炼实时（`rt_voice` + `audio_fx` 仅做 rate/pitch），文字/分模型才走 TTS；实时音频不得改走 MiMo/其他 TTS，避免换音色。
> - **保留正确性**：会话锁/配置锁/原子保存、按 `turn_id`/`ignore_responses`/`pending_audio`/`stream_epoch` 隔离迟到结果、按键 `abort` 取消，均不可因“Agent”改动而削弱。**语音插话打断受设备 AEC 限制（本板上游未开放），不能假设可用。**
> - **助手层**：提示词/所选工具/所选知识库经 `build_system_prompt(channel, ...)` 与工具注册注入；知识库检索按所选库 ID **服务端硬过滤**（多库规划中，未实现）。

适用于开发工作；2026-10-17已授权文字配置、MiMo TTS独立配置与浏览器草稿试听、统一设置入口及页面精简，均已隔离验证；设备、ASR和部署等仍不在本轮范围（历史）。

## 技术基线

Python 3.11+，现有Windows环境历史使用3.12；FastAPI、Pydantic、异步HTTP和OpenAI兼容适配器；原生HTML/CSS/JavaScript；SQLite完整历史；独立设备网关。依赖按现有requirements固定版本，不为整理规范升级库、改框架或添加构建链。

## 实现与模块

- Python缩进4空格，模块/函数snake_case、类PascalCase、常量UPPER_SNAKE_CASE；JS沿用camelCase和当前原生DOM风格。
- 名称表达职责，不使用无意义单字母变量。保留现有文件风格，禁止无关格式化和重命名。
- 对话、模型、历史、语音、设备协议各有边界；先复用已有服务层和Protocol，再增加一个必要适配器。
- HTTP/JSON输入使用schema校验，失败返回稳定错误码和可理解信息；不回显API上游原文或包含密钥的输入。
- UI按不可信内容渲染模型文字，CSP、Origin和输入限制不得随意移除。不新增代码内行注释，除非用户明确要求。

## 必须保持的正确性

- 完整历史和模型最近N轮上下文独立，设置保存不清空历史；不要把所有历史重新发送给模型。
- 当前请求切换锁、会话锁、原子配置与数据快照写入是正确性机制，不是可跳过的行政状态。单进程运行，不擅自添加workers。
- 按键结束、语音打断和取消不能排在慢模型/配置锁之后；保留等效一致性机制，按会话/轮次/连接隔离迟到结果，不能以删除锁或放任旧音频回灌换响应。
- （历史 M4 标签）历史分页/详情按需加载与有界活跃上下文：不让在线长期历史全部常驻内存；超过旧历史数量限制仍可新建，不扩大max_sessions或要求删历史来伪装达标。
- 模型失败不污染上下文，不自动重试付费请求；未知Token、单价和费用保留未知。已有模型回复不能因TTS失败重复请求。
- 设备随机凭据、MAC配对、能力协商、回执/读回区分继续保留。屏幕无回执时须人工观察。
- 设备入口与管理入口隔离；公网迁移必须提供正式身份认证与等效保护，不能放宽allowed_hosts、Origin或回环限制来绕过迁移工作。
- 认证与TLS/WSS在**首次公网联调前（旧称 M3）**验证，M5（旧标签）仅作受影响回归，不允许为了先测声音裸露管理、历史或设备控制。
- 密钥只在服务端环境变量/私有配置中保存；不写固件、浏览器存储、示例、日志、测试快照或agent文档。
- 未来插件必须校验参数并限制权限，不运行模型直接给出的任意代码。高风险操作另行确认，现阶段电脑控制不在范围。

## 下载与资源

全部Windows下载、模型、安装包、缓存和语音环境留在项目内；安装与下载命令显式指定TEMP、TMP、PIP_CACHE_DIR、HF_HOME、TORCH_HOME。保留 `.venv-speech` 隔离和随包许可；不为试听安装未确认的GPU环境。

## 开发方式

以根目录 AGENTS.md 的最新用户指令为准：直接完成已授权的真实功能，不默认建立测试隔离、模拟API、假数据、最小验证、分级验收或额外测试后台。不为假想需求增加多层兜底、通用框架、自动重试链或兼容分支。

实际故障修复根因，不机械重跑历史流程。已有测试保留，不自动扩展或执行；历史测试结果不代表真实服务可用。不以测试、类型检查、截图或文档完整度作为交付门槛，如实报告实际运行结果和未运行项。

范围内自主推进；不因上述开发方式改变而删除鉴权、密钥保护或数据一致性机制，不自动获得下载、安装、设备操作、真实API调用或部署授权。不提交Git。
