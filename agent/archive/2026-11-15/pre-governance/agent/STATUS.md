# 规范基线状态

更新：2026-11-08。

- 产品：一个硬件语音助手，正常对话，理解需求、按需调用 API 与所选知识库，简单、高效、快速；不缩减或扩大这个目标。
- 设计：集中提示词/选 API/选库；API 能力统一天气/M5Stack/自定义 API；多独立知识库；现有工具反馈循环与实时音频增量完善。
- 范围：无多助手系统、长期记忆、无人值守任务或重型规划平台。开发团队多个 Bot 只表示分工。
- 技术：Python/FastAPI、原生页面、SQLite、小智兼容网关，百炼 Omni 实时主线；灰阶明暗主题沿用，不因 Agent 改造换音色或第二套模型链。
- 当前工作：用户要求同步全部项目自有文档及消除冲突；本轮只改文档。产品方向已明确，功能实现/验证状态不因本文更新而改变。
- 状态判定：基础设备交流已由用户现场确认；助手能力/库选择、多库归属等仍待实现。实际证据只看 [progress](docs/progress.md)。
- 操作边界：主 Bot 统一调度服务、设备、迁移与付费；不擅自提交/部署/烧录/改地址/下载安装。文档同步不自动执行这些动作，已授权常规工作不重复逐步请示。

整体设计看 [architecture](docs/architecture.md)，范围看 [PRD](docs/prd.md)，执行看 [roadmap](docs/roadmap.md)，接着做什么看 [START](START.md)。

旧 `frozen`、M0–M5 及 2026-10-17 的弹窗/三页签、仅 M1 授权记录不再作为当前规范或开工顺序；历史决定及证据在 [decisions](docs/decisions.md)/[progress](docs/progress.md) 保留。保留已有行为是为了不破坏实际可用功能，不是阻止用户明确提出的迭代。
