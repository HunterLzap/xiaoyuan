## 当前责任划分（2026-11-07）

AI 交付与用户现场体验分开，具体清单见 [roadmap](roadmap.md)。AI 先完成范围内完整功能与可独立确认的实际运行，再交用户集中体验；不要求逐个小步骤人工批准或先试用。冒烟、模拟 API、假数据、隔离测试后台、最小可行性和分级验收不是执行流程；下文旧表中的这类安排已撤销。

已有 A1–A17 保留作行为参考，旧 M 阶段编号不再决定开发顺序。API 工具与个人知识库的 AI／用户任务直接引用 roadmap 的 P1，不另建重复测试表。网关首包、协议回执、真实扬声器出声和听感分别表达；未做用户测试不能标成最终通过，也不能阻塞无依赖开发。

更新：2026-10-17。用户确认的范围以PRD为准，以下是可执行验证方案，不是通过报告。M1的API配置部分已获授权并做隔离验证；实际结果与未验收项只在 [progress](progress.md) 维护，本文件不重复充当完成状态表。

## 1. 判定和样本

- 结果记“通过/失败/未执行”及环境、输入、实际输出、依据；代码、模拟、部件、真实账户、实机、目标云端分别说明。
- 最小样本建议：桌面及客厅约1–2米/日常电视或音乐各10轮有效问答、各至少两段，覆盖唤醒和按键；加空语音、结束词引用、打断、自播、故障用例。样本量是测试方案，不是用户承诺长期可用率。
- 固定接口/模型/ASR/TTS/音色、正常网络和摆放，逐轮记首声；从实际说完到实机回答约3秒，提示音不计。每个超过3秒的样例单独标未达到目标，不用平均数盖住；未达时需证据与用户取舍，不自行判通过。
- 打断停止耗时与回答首声分开；当前没有用户确认的毫秒级打断阈值，先测并请用户实际判断，不伪造数值SLA。背景音条件实测记录，不承诺任意音量。
- 约3秒、30秒静默、供应商超时、30天副本各司其职。网络故障看失败/重连行为，不用固定“处理中”冒充成功回答。
- 不保存私人录音当永久验收附件；必要固定样例或临时校准按隐私策略清理。记录不得含密钥、令牌、私人问答或完整设备身份。

## 2. 行为用例

| 编号 | 操作 | 通过条件 | 首次/最终阶段 |
| --- | --- | --- | --- |
| A1 真实模型 | 准确配置下两轮实际问答；另测配置错误 | 回答与段内上下文正确，真实用量/未知项如实显示，错误脱敏，不自动重试 | M1 / M5 |
| A2 设备语音与分段 | 两组环境分别唤醒和按键，段内追问，结束再唤醒，空语音 | 可听清，段内连续、跨段请求不含旧问答，旧文字可查，空输入不调用模型 | M3基础、M4完整 / M5 |
| A3 配置与实机效果 | API配置入口；获取/选择或手填模型；草稿测试/保存；另测角色/音色/支持的硬件项 | 列表成功、空、不支持、鉴权失败/超时区分且保留输入；列出不当作调用成功、不自动试遍模型；草稿不覆盖已存配置、不清空历史、不返回已有密钥；硬件保存/发送/回执/读回/观察分开，同轮不混配置 | M1配置、M2硬件、M4完整 / M5 |
| A4 历史与重启 | 真实对话后刷新、保存设置、受控重启再查看 | 未删全文和已有元信息仍可查，模型仅收N轮；不自动重放活动回答或把旧段绑定新唤醒 | M1现有、M4完整 / M5 |
| A5 存取与删除失败 | 核对真实写入/删除失败的提示与数据保护；针对实际故障定位，不人为损坏在线库或搭隔离模拟后台 | 已生成回复保留并提示，删除失败不伪报成功，不自动清空库或忘掉记录 | M4 / M5 |
| A6 实机入口 | 实际OTA发现、WS鉴权、协商、连接状态、支持项控制 | 每一步独立证明，错误身份拒绝，不支持如实显示，屏幕需人工观察；非模拟设备 | M2 / M5 |
| A7 原平台恢复 | 清空自定义OTA恢复原值；自建网关不可用时原平台对话 | 实际独立对话成功，不只看在线；保留绑定，无固件烧录/升级 | M2 / M5受影响时 |
| A8 失败与重连 | 短断恢复、静默/处理超时后恢复、错误设备、旧连接回调、各供应商失败 | 同一合法设备接回未结束段，已结束不复活，不重播/重提请求，不拼坏输入，旧连接不覆盖新连接，有界等待 | M4 / M5 |
| A9 外网管理与保护 | 外网手机/电脑个人登录；未登录访问全部受保护业务；错误设备凭据/不合规请求 | 登录可管理，未登录不可读历史/配置/用量或控制/聊天；TLS和设备鉴权独立，非敏感登录资源正常，原有防护等效 | M3首次公网前 / M5 |
| A10 低配云端独立运行 | 关闭Windows，目标服务重启，连续对话/翻页/取消/备份并观察 | 语音/管理/历史/备份均无Windows依赖，资源在事先约定上限内且无持续泄漏，原语音站正常，未隐含加载大模型 | M3基线 / M5 |
| A11 双环境约3秒首声 | 固定实际配置，在桌面与约1–2米日常客厅分别测整链路 | 识别与回答有效，逐轮达到约3秒目标，超出单列，不能只报API/均值或以提示音代替 | M3 / M5 |
| A12 隐私、临时音频与用量 | 完成/失败/打断/按键结束/重启后的文件和日志核对，查看已有用量 | 不长期留录音/音频，不入普通日志或备份；文字按约定保存，真实用量与费用未知项不补造，无预算gate | M3基础、M4完整 / M5 |
| A13 30秒静默 | 实际播完后等待；30秒内讲话；处理或播放超过30秒 | 无讲话30秒结束，继续讲话取消旧计时，处理/播放不误结束；新唤醒新段、旧历史保留 | M4 / M5 |
| A14 双环境语音打断 | 桌面与约1–2米背景声中播放时直接讲话；另测自播和连续打断 | 实机停止旧声音/缓冲，发言开头不丢，无需再唤醒、仍在本段，无旧音频回灌或循环误触；单测停止耗时 | M3 / M4、M5 |
| A15 长期历史与容量 | 使用实际历史核对翻页/详情/新建与受控重启；超过旧 max_sessions 的实际容量场景按已有证据核对，不造假历史或要求用户删记录 | 新会话不被旧历史堵住，按需加载、活跃容量保护仍有效，无按天自动删在线记录 | M4 / M5 |
| A16 主动结束与屏幕键 | 明确结束语/引用词普通问题，收音/生成/播放时按屏幕键，再唤醒；注入迟到结果 | 引用不误触，按键不等模型返回就停止/结束/待机，迟到结果不重播；再唤醒新段、旧记录仍在 | M2事件、M4完整 / M5 |
| A17 每日云备份/30天副本 | Windows关机时生成独立一致性副本并实际恢复（不搭隔离测试后台）；模拟日期、目标故障、任务重入及已删除记录 | 每日一次不重叠，30天轮换不删在线库，不含录音/明文密钥，内容可恢复，失败可见不拖住聊天，恢复不静默复活已删记录 | M5 |
| A18 唤醒反馈 | 叫“塔菲”唤醒；观察是否有明确反馈 | 屏幕明显显示“聆听中”与/或唤醒提示音清楚，用户能立刻知道已被唤醒、可以说话 | M2事件、M4完整 / M5 |
| A19 语音结束与再唤醒 | 说“闭嘴/关机”结束；稍后再叫名字 | 结束回到待机；再叫能重新唤醒并开启新段，旧历史保留 | M4 / M5 |

策略测试可使用模拟时钟/副本日期，不需要等30天；同时必须至少一次真实独立目标写入与实际恢复（不搭隔离测试后台），不能把模拟时间测试冒充真实备份运行30天。

补充A3配置验收：设置按角色与声音、API接入、能力管理（工具/知识库）、数据洞察分层；验证接入→候选模型→声音→试听→保存→刷新恢复。连接与日常选择只修改各自字段，未保存连接不污染日常测试/试听；文字/TTS密钥独立，历史保留。对两种MiMo TTS分别验证内置音色和必填描述、草稿合成可播放WAV、失败保留输入、取消与旧音频回收；在途试听不混新配置、不阻塞保存。按用户配置验真实API/听感，不搭隔离模拟，不将浏览器试听当设备播放通过。
