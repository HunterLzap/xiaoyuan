## 实现接续

- 助手设置集中提示词、选用 API、选用一个或多个知识库，沿用 SettingsStore，不做多助手表或切换系统。
- API 能力统一列出天气、M5Stack 和自定义 API；管理资源与助手选用范围分开。个人知识库走多库管理与选库，不再多一条让用户困惑的检索总开关。
- 复用 ToolRegistry/TurnTools、提示构建、真实工具结果与审计；多步调用沿用模型反馈循环，不加每轮前置规划请求。
- 百炼 `qwen3.8-omni-flash-realtime` 是当前实时主线，设备/网页语音与实时模式网页文字共用；保留塔菲音色、语速/音调、正式第一句开场及现有停止/迟到隔离。分模型路径不替换实时音频。
- 多库归属、选库硬过滤、旧资料迁默认库、三页与资料上传/替换已实现，真实运行证据见 progress。双库关键词隔离已实跑，向量隔离仅代码核查；当前1库1文档，临时验证资料已清理。不要重做迁移或把向量隔离/语音链自动记为通过。
- 查询按已开放范围自动用；外部修改/发送/删除/付费在接相应服务时必须具备具体确认流程，未实现时受限。设备确认应在下一轮进行，不能依赖当前不具备的播放中语音打断。
- 本板 AEC/收放同听是独立设备约束，按键 abort 有历史证据，Agent 改造不能冒称解决插话打断。具体限制看 operations/references。

## 团队与运行调度

- 先盘点并复用现有 Bot，不为文件数量或平台外观创建角色。主 Bot 拆目标、划文件归属、集成运行；子 Bot 负责所属模块，开发多个 Bot 不等于产品多个助手。
- 每项任务明确模块、输入/输出、依赖、实际交付与剩余限制；同一文件同一时间一人改。不能用“测试通过”替代真实行为证据。
- 服务启停、设备、迁移、付费请求等由主 Bot 按授权统一调度。保留配置/历史/知识资料/音色，不启动冲突实例，不重复计费。
- AI 完成能独立进行的开发、真实运行和修复；用户集中做讲话/听感/按设备/物理场景等现场体验。普通实现选择由负责人处理，不向用户索要工程方案。
- 不搭模拟 API、假数据、隔离测试后台，不走冒烟/最小验证/分级验收；不加无依据通用兜底。鉴权、密钥、参数、并发、取消和数据保护保留。
- 不擅自 commit/push/部署、烧录、改设备地址、下载安装或操作远端；已有密钥不等于无限付费请求。真正外部依赖缺失只阻塞相关能力，不停止其他独立工作。
