> **当前口径（2026-11-08）**：本文件记录的是 **MiMo `mimo-v2.5-tts-voiceclone`** 的克隆流程，属**分模型/文本 TTS 的历史与候选**。**实时主线不用 MiMo**——设备/网页语音的实时音色是**百炼塔菲复刻（`AI_RT_VOICE`）**，由百炼实时会话直接出声，不经本地 MiMo 合成。保留本文件作历史复用参考，不代表当前实时链路做法。

状态：**原位归档的MiMo历史记录**。本文件保存2026-10-18当时的流程、参数和未完成界面建议；“当前”“尚未实现”“不要点保存”等均只指当时MiMo分模型版本，不是现行百炼实时指令。当前声音与网页功能以START/代码为准，不执行本文克隆/调用步骤。

## 一、原理

声音模型内部用「音色向量」表示音色，不是音频文件。

| 项目 | 数据 | 说明 |
| --- | --- | --- |
| Kokoro 本地模型 54 个音色 | 26.9 MB | 每个音色 510×256 float32 ≈ 510KB |
| 预置音色请求 | 一个名字（几十字节） | 音色向量已在服务端 |
| 克隆音色请求 | 每次都上传参考音频 | 服务端现场提取音色特征 |

**这是克隆慢的根本原因**：每句话都要重新上传参考音频并重新提取特征。
实测把样本从 397KB 压到 50KB 后，速度从 11–36 秒降到 2.5–3.2 秒，与预置音色持平。
因此**样本体积是关键**，不是模型能力问题。

## 二、模型与参数（MiMo V2.5 TTS）

可用模型（TokenDance 通道已确认存在）：

- `mimo-v2.5-tts` — 预置音色
- `mimo-v2.5-tts-voicedesign` — 文本描述生成音色
- `mimo-v2.5-tts-voiceclone` — 音频样本克隆音色

克隆调用的关键结构：

```json
{
  "model": "mimo-v2.5-tts-voiceclone",
  "messages": [
    {"role": "user", "content": "<风格指令，可为空>"},
    {"role": "assistant", "content": "<要合成的文本>"}
  ],
  "audio": {
    "format": "wav",
    "voice": "data:audio/mpeg;base64,<参考音频的 base64>"
  },
  "stream": false
}
```

要点：

- 待合成文本必须放在 `assistant` 消息，放在 `user` 会被当成指令。
- `user` 消息用于控制语气风格，实测能改善咬字清晰度。
- `voice` 字段带 `data:<mime>;base64,` 前缀，支持 `audio/mpeg` 与 `audio/wav`。
- 参考音频上限 10 MB（base64 编码前）。

## 三、本次实际步骤

### 1. 选样本

- 来源：用户提供的 `Taffy/` 目录，711 个 wav（44.1kHz 单声道 16bit，1.1–13.8 秒）。
- 自动筛选：按「人声占比 ≥0.75、音量稳定性 ≤0.45、时长 ≥6 秒」打分，711 个里只有 6 个合格。
- 大部分样本含停顿、杂音或音量起伏，**克隆会把这些一起学走**，这是首要质量因素。
- 最终选中 `Taffy_365.wav`（8.91 秒）。

### 2. 预处理

原文件 44.1kHz/767KB 直接送会慢。处理成 24kHz 单声道并裁掉首尾静音：

```
源文件 767 KB (44.1kHz)
  → 24kHz WAV 397 KB   （仍偏大，实测 11–36 秒）
  → 24kHz MP3 48kbps 50 KB  （实测 2.5–3.2 秒）✓
```

产物：`models/voice/taffy-24k.mp3`

### 3. 风格指令（改善咬字）

实测对比：同一干净样本，加指令后语序更稳、含糊发音减少。

```
用活泼轻快、带点主播感的语气说，语速正常，咬字清楚，不要含糊。
```

### 4. 落地配置（分模型/文本 TTS 生效时；实时模式不适用）

> 说明：以下 `.env` 是 **MiMo 分模型/文本 TTS 路径**的配置，**不作用于实时模式**（实时音色由百炼 `AI_RT_VOICE` 塔菲复刻直接出声）。当前主线为百炼实时，下述为历史/分模型做法。

`.env`：

```
AI_TTS_MODEL='mimo-v2.5-tts-voiceclone'
AI_TTS_INSTRUCTION='用活泼轻快、带点主播感的语气说，语速正常，咬字清楚，不要含糊。'
AI_TTS_CLONE_SAMPLE='models/voice/taffy-24k.mp3'
```

代码位置：

- `backend/app/config.py` — `tts_clone_sample` 字段
- `backend/app/tts.py` — 克隆分支，`resolve_sample()` 限定样本必须在项目内
- `backend/app/settings_store.py` — `tts_clone_sample` 已加入两个更新模型

## 五、历史问题快照（2026-10-18，不是当前操作指令）

以下代码行号、下拉选项和保存风险是当时 MiMo 分模型的记录，后续代码已变化；不能据此要求当前用户不要保存设置，也不能把它当成百炼实时塔菲音色的现状。当前事实以 [progress](progress.md) 及当前代码为准。

1. **网页下拉没有 clone 选项**：`backend/app/app.html` 的 `tts_model` 只有
   `mimo-v2.5-tts` 与 `voicedesign` 两项。
2. **点一次保存会覆盖配置**：`app.js` 第 278 行直接提交下拉框的值，
   下拉里没有 clone，所以保存后 `.env` 里的 clone 会被改成预置模型，塔菲声音丢失。
   **在补界面之前，不要在网页上点保存。**
3. **限流**：连续合成多段会触发 429（实测 8-10 次后出现），单次重试或稍等可恢复。
