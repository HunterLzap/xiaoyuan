## 仍长期保留的基础规则

- **音频隐私与长期文字历史（D13 / D14 / D20 / D26）**：不长期保存对话录音；完整文字历史持久化保留（仅用户手动删除），每次硬件唤醒开启新段隔离模型上下文，不因保存设置清空历史。
- **交互结束与打断规则（D15 / D16 / D23 / D24）**：播完 30 秒静默结束、明确结束意图结束、活动中屏幕键结束待机；播报中开口打断与桌面操控即时喊停互不干扰，迟到旧音频隔离。
- **每日独立备份目标（D25 / D27–D29）**：每日 SQLite 热备并向独立异地目标保存 30 天副本且验证恢复；目前待实施上线。
- **设计视觉规范（D07）**：沿用现有 Codex 灰阶明暗主题与暖琥珀金强调色，不另换品牌配色或重型前端框架。
