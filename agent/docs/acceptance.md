# 行为判定与需求覆盖

更新：2026-11-15。本文件定义如何判断行为，不是完成报告、固定测试流程或操作授权。当前结果见 [START](../START.md) / [progress](progress.md)；卡顿已按用户要求暂缓。

## 判定原则

- 区分设计目标、已有代码、AI真实运行、用户现场确认。模型completed、HTTP200、网关首包/发完、设备收到和扬声器播放是不同层次证据。
- AI完成范围内可独立处理的实际工作；用户集中负责讲话、听感、按键、摆放等现场条件。已有用户“恢复了”反馈保留，不要求为整理文档重测。
- 按实际相关改动选必要检查，不默认固定轮数、模拟API、假数据、影子/隔离后台、冒烟/分级流程或“所有用例先全过”门槛。
- 约3秒是说完到实际扬声器回答首声的目标，30秒是实际播完后的静默计时，30天是备份副本期限；不混淆，也不以均值或提示音代替。
- 配置、声音和网络条件改变后，只能按实际影响说明证据范围；不自动重跑全部历史或批量请求付费模型。
- 不保存私人录音作永久附件；用量/价格缺项保留未知，不补造通过或费用。

## 行为覆盖

| 编号 | 需求 | 判定依据 |
| --- | --- | --- |
| A1 | R02真实模型与用量 | 使用实际配置正确回答；供应商返回用量准确保存，失败脱敏，不自动重试计费请求 |
| A2 | R03/R04设备唤醒与分段 | 待机可唤醒、段内追问、结束后新段隔离，空语音不提交模型；旧文字保留 |
| A3 | R09配置与实机效果 | 获取列表/草稿调用/保存分开；不返密钥、不清历史；硬件保存/发送/回执/读回/观察分开 |
| A4 | R10历史与重启 | 未删原文和元信息可查；只带必要上下文；重启不重播活动回答 |
| A5 | R10存取与删除 | 真实失败如实提示，保护原数据，不清库或伪报删除成功 |
| A6 | R13设备接入 | OTA、WS鉴权、协商、真实会话分别确认；已有云端成功证据不能退回“尚未切换” |
| A7 | R13原平台恢复 | 仅获具体要求后恢复已记录原值；不依赖自建网关也能真实对话才算恢复 |
| A8 | R07失败与重连 | 未结束段合法恢复；已结束不复活，不重播/重提供应商请求，旧连接不覆盖新连接 |
| A9 | R09公网管理边界 | 按用户决定免登录；HTTPS/WSS、独立设备鉴权、内部代理凭据与同源/写校验保留，不按旧要求加回密码 |
| A10 | R02云端独立运行 | 设备/管理/历史无需Windows服务；不能以已部署推断备份也已交付或所有听感通过 |
| A11 | R08双环境首声 | 桌面及约1–2米日常背景条件分别说明实际结果；逐轮超时如实报告，不用提示音代替回答 |
| A12 | R11音频隐私与Token | 不长期保存聊天录音；输入/输出/文字/音频/缓存/响应数按实际回报，未知不补0，不当供应商账单 |
| A13 | R05静默结束 | 实际播完后30秒计时，发言取消旧计时；收音/生成/播放不误结束 |
| A14 | R06播放中插话 | 停旧实际播声/缓存、保留新发言开头、同段继续，无旧轮音频回灌；握手aec标志不能代替听感 |
| A15 | R10长期历史与容量 | 分页/详情按需加载、活跃缓存有界；不自动删在线记录或要求用户清历史才能使用 |
| A16 | R05结束语与屏幕键 | 真正结束待机，引用结束词不误触；旧结果不重播，新唤醒新段 |
| A17 | R12独立备份 | 实际独立目标每日一致性副本、保留30天并能恢复；不只看文件存在，不恢复已删记录到日常可见 |
| A18 | R03唤醒反馈 | 用户能从声音或屏幕明确知道已进入聆听，不能以服务日志代替 |
| A19 | R05结束后再唤醒 | 主动结束后可再叫名字进入新段；连接关闭码1000不是状态机完成证明 |
| A20 | 工具意图与任务加载 | 报数不调音量，明确控制正常；复合候选取并集，追问与同轮加载保留，真实结果续答 |
| A21 | 多库与知识依据 | 助手所选库限制真实检索范围，关键词与向量均不跨库；替换/删除不伪造旧出处 |
| A22 | 天气省略追问 | 目标城市/日期与成功结果覆盖匹配；不覆盖时真实查询，不把旧日温度改日期口述 |

## 当前证据边界

助手选库、多库迁移/关键词与hybrid隔离、实时文字工具组合/引用、文字工具加载与Token明细已有各自证据；11月15日稳定恢复用户确认有效，21:26–21:28云端设备问答也已确认。

当前用户明确仍有随机卡顿，暂不解决；云端全部播放听感、每个结束词、所有场景下的打断/重连不能补写通过。语音按任务加载与查询覆盖方案尚未接入，云备份尚无完成证据。

旧M0–M5、仅M1授权、固定样本量和模拟日期等不再决定执行顺序。决定演变见 [decisions](decisions.md)，不把旧方案变成每轮必走清单。
