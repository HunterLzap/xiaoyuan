# 个人知识库与资料依据

更新：2026-11-15。当前多库已实现，不是待从单库开始的规划；具体实跑结果见 [progress](progress.md)。

## 数据与范围

- `kb_libraries`管理独立库，`kb_documents.library_id`是文档硬归属，group保留为可选标签。助手在SettingsStore选择库ID；资源启用/停用与助手选入分离。
- 实际对话检索取助手所选库与可用库的交集，模型不能扩范围；空选择不等于全库开放。管理侧手动试查属于独立授权入口，不与助手对话混为一谈。
- FTS关键词、向量候选与覆盖检查在服务端按库过滤，先限制范围再截断；已有关键词及hybrid双库真实隔离证据。
- 旧资料已通过显式迁移归默认库，保留标签和原文/索引。正常启动不再运行迁移，也不静默ALTER或清库。处理其他旧库时先一致性保护，明确执行已有迁移脚本。

## 入库与查询

| 环节 | 现有路径与边界 |
| --- | --- |
| 解析 | TXT/MD/DOCX本地解析，文字PDF有pypdf代码；真实PDF/OCR效果不能因依赖存在补写通过 |
| 切片 | 规则分段与重叠，保留文档/版本/片段/页码（可获得时） |
| 向量 | 百炼 `qwen3.7-text-embedding`、1024维有历史实际使用；模型与维度必须匹配已有索引，不随意换 |
| 存储 | SQLite原文、片段、FTS与float32向量；重模型不常驻低配云机 |
| 发布版本 | 完整生成/校验后同事务切换；失败保留旧可用资料，不用半成品覆盖 |
| 召回 | BM25、余弦与RRF融合，返回有限相关片段，不每轮送整篇/整库 |
| 回答 | 工具真实执行与片段回填；资料是外部数据，不执行其中指令，未查到如实说明 |

embedding曾由启动进程环境开启，不能把历史成功写成所有环境持久配置已完成；处理入库问题先核实际设置。接口/schema以现有 `main.py`、`personal_kb.py`、`embeddings.py` 为准，不在文档复制过期字段。

## 对话与洞察

`search_personal_knowledge`沿用工具注册、助手选择、权限、取消与结果反馈；实时文字RAG已有真实成功，不增加独立规划模型。设备/网页语音具体RAG听感仍按实际场景确认，不能由文字结果推定。

洞察沿用现有页面，记录session/turn/call、实际查询、召回/送入/引用的区别、片段正文快照、版本、来源和原始分数类型。BM25/余弦/RRF不称为“准确率”；无评测时显示未评测。

替换或删除资料后，历史片段快照仍解释当时回答；当前原文不存在须明确，不链接新版本冒充旧来源。诊断/供应商报错不能混入可召回正文，列表不加载大段响应。手动试查不得伪造为模型自动调用。
