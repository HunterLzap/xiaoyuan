# 产品目标与边界

## 产品目标（2026-11-15维护）

一个**个人自用的硬件语音助手**（AtomS3R + Echo Base）：正常语音聊天，能理解需求，按需调用已配置的 API 与所选个人知识库把事办成；简单、高效、快速。具备基础工具反馈循环（模型判断→调用工具→按真实结果回答），不做多助手系统、跨会话长期画像或重型规划平台。配置集中在一处：提示词、选 API、选知识库；多库、服务端硬过滤与会话内历史检索已有实现，范围见START。

## 一句话定义

为设备所有者本人建设一个以小智基础体验为参照、能正常语音交流、网页管理和查看聊天历史的个人硬件语音助手；需要时按配置调用 API 与个人知识库工具把事办成。

## 为什么做

用户对硬件与 AI 有兴趣，希望拥有一个可理解、可改造、可持续升级的机器人。当前没有确认必须解决的高频效率刚需，不编造省时、陪伴或商业收益作为项目立项理由。

第一版的价值是获得自己可掌控的基础体验，并证明现有硬件、后端、语音与历史能够可靠协同。后续功能由真实兴趣和使用结果选择，不按“个人 Agent 应有功能大全”扩张。

## 已确认范围

- 第一版：语音聊天、网页管理、聊天历史。
- 语音唤醒和按键都要；文字历史保留、不长期保存录音；每次唤醒开启一段新会话，段内连续、跨段隔离上下文。
- 回答实际播放完后30秒无后续讲话结束；播放中直接说话打断是保留目标。网页支持外网手机/电脑访问；用户已明确免登录，保留HTTPS/WSS及设备鉴权，不恢复账号密码。
- 支持语音主动结束及正面屏幕按键结束待机，下次唤醒新段、不继承旧上下文。文字历史每天自动备份到独立云存储或另一服务器，副本保留30天并验证可恢复；具体服务待配置，在线文字仍一直保留。
- 桌面安静近距离与客厅约1–2米、电视/音乐背景均为目标，首声目标约3秒；文字历史一直保留，由用户手动删除。短暂断网只接回未结束段、不重播；实际确认范围逐项看progress，不抹掉已有稳定恢复确认。
- 个人使用、低成本、模块化、可维护；供应商可替换。
- Windows本地开发，2核约1.87GB云服务器已部署且设备已接云；独立运行仍是要求，不等于备份及全部现场体验已交付。
- 接受在线语音识别与合成；API由用户配置、费用由用户管理，不以固定月预算作为前置确认项。
- 电脑控制先不做；以自有云端平台为交付方向，现有固件与兼容组件按需要复用，原平台保留恢复路径。
- 当前不刷固件/资源、不接新动画、不再改已接通的OTA；本轮只整理文档，整段回答随机卡顿按用户要求暂缓。

## 成功的判断

设备真实说话与播放；网页配置对实际行为有效；刷新与重启后能查看对应记录；失败可被解释和恢复。完整标准见 [验收](acceptance.md)，当前完成度见 [进度](progress.md)。

## 不作为第一版目标

复刻小智全部功能、商业多租户、多助手平台、复杂编排、全本地推理、任意桌面自动化、智能家居全接入、长期记忆、通用大知识库。个人知识库（用户自己上传资料、服务端按所选库检索）已纳入范围，不属此处排除的“通用知识库”。保留扩展边界，不提前建设数据库集群、消息队列或复杂 Agent 框架。
