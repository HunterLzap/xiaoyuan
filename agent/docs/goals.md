# 产品目标与边界

更新：2026-11-25。

## 一句话定位

一个**个人自用的硬件语音与个人电脑 Agent 工作台**（AtomS3R + Echo Base + 网页工作台 + macOS/Windows `desktop_node`）：日常自然语音和文字聊天，理解用户意图，按需调用百炼原生联网搜索、所选个人知识库、M5Stack 官方资料、自定义 HTTP API，以及经明确确认后的本人电脑操控，用真实结果把事办成；简单、高效、快速。

## 核心设计原则

- **单助手，不平台化**：只有一个助手，集中管理人设、工作档案、声音配置、API/技能与所选知识库。不做多账号、商业多租户或独立重型规划平台。
- **复用实时循环与安全门禁**：复用百炼实时与现有工具反馈循环；写操作与电脑操控统一经过确认卡片/语音确认与有限租约保护，不取消鉴权与凭据拦截。
- **真实结果导向**：模型根据用户意图与真实工具/屏幕观察决定下一步；功能价值以“实际跑通并帮到主人”为准，不按“功能清单堆砌”扩张。

## 当前纳入范围

1. **硬件与网页双端对话**：AtomS3R 语音唤醒（“塔菲”）与正面屏幕按键交互、网页沉浸式语音与文字工作台，统一写入 SQLite 持久文字历史。
2. **上下文与记录管理**：单次唤醒段内多轮连续、结束或新唤醒开启新段隔离上下文；完整文字历史长期保留、不长期保存聊天录音；在网页「记录」查看会话级对话历史与逐轮「Agent 执行轨迹」、知识库检索、工具调用与脱敏异常日志。
3. **联网、知识库与电脑操控**：百炼原生联网搜索（统一承担常规联网与天气查询）、多独立个人知识库（服务端按选库硬过滤）、M5Stack 官方只读资料、自定义 HTTP API，以及跨平台 Windows/macOS 电脑 GUI/应用/剪贴板/命令行操控（含语音与网页即时喊停打断）。
4. **独立云端运行**：2 核约 1.87GB 云端独立承载服务、网页与历史存储，网页按用户意愿免登录（保留 HTTPS/WSS、独立设备鉴权、内部代理凭据、同源保护与公网屏蔽桌面节点管理）。每日独立备份与恢复演练保留为运维目标。

## 明确不做的范围

- 多助手系统、商业多租户、团队协作账号体系。
- 跨会话长期用户画像或后台无人值守定时巡检 Agent。
- 智能家居全量平台接入或本地全离线大模型推理。
- 未经用户要求的固件大改、新动画强制接入或额外预算审批门禁。
