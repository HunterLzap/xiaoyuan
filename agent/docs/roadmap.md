## 实施原则

1. 优先参考官方资料和成熟项目已有实现，再适配当前工具注册表、SQLite与实时循环；不为了“抄作业”引入整套框架。
2. 工具选择保留复合指令候选并集、追问状态和同轮补充加载，不能只对单句话做不可逆分类。
3. 共享策略不代表所有通道时序相同。网页文字已生效的优化，只有明确协调语音事件后才接入实时语音。
4. AI完成已授权范围内的实际工作，用户集中负责听感和物理条件；不重复要求确认工程小步骤，不批量调用模型充当进展。
5. 不默认安排模拟/隔离后台、固定样本量、影子环境或分级验收。必要校验、数据保护、取消与迟到隔离继续保留。

完成依据见 [acceptance](acceptance.md)；真实结果只记 [progress](progress.md)。旧M0–M5和P0–P3不是当前执行顺序，也不是部署、刷机或付费授权。
