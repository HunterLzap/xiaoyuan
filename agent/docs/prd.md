# 产品需求

更新：2026-11-25。本文定义当前产品行为规格；实际代码、云端发布与实测状态见 [START](../START.md) 与 [progress](progress.md)，不把目标写成全部场景已完成实机验收。

## 产品范围

产品定位为**单用户个人语音与电脑 Agent 工作台**：正常语音/文字对话，理解用户意图，按需调用百炼原生联网搜索、所选个人知识库、M5Stack 官方资料、自定义 HTTP API，并在用户启用和授权后观察/操控本人的 Windows 与 macOS 电脑，简单、高效、快速。**不做多账号多助手平台、跨会话长期自动画像、重型多 Agent 编排或无人值守后台任务**。

- 配置围绕单个个人助手统一组织：**模型**（精简为「日常对话与语音」「电脑操控模型」两张卡片 + 折叠高级设置）、**人设与声音**（系统提示词、`agent_profile`、百炼复刻音色与语速/音调）、**能力与知识**（统一单开关同步启用与选入，含原生联网搜索、M5 官方资料、`个人电脑操控`、自定义 HTTP API 及多独立个人知识库）、**设备**（电脑节点与 AtomS3R 硬件）。后端 `/api/assistant/selection` 隔离逻辑继续保留并由前端同步。
- 写操作与电脑操控（打开应用/链接、GUI 键鼠操作、写剪贴板、终端命令及外部改/发/删/付费 HTTP 工具）走统一确认门禁：支持网页对话内交互式「确认执行 / 确认并免问电脑操控 (3 分钟) / 取消执行」卡片及语音/文字下一轮“确认/取消”；凭证文件（`.env`、`.ssh`、私钥、Keychains）服务端与桌端双重硬拦截不可读。

## R01 核心场景

面向设备所有者本人（AtomS3R + Echo Base + 个人 Mac/Windows 电脑），覆盖三个核心日常场景：

| 核心场景 | 触发与交互 | 期望结果 | 失败处理 |
| --- | --- | --- | --- |
| 语音与文字对话 | 硬件语音唤醒/按键，或网页语音/输入提问，段内自然追问 | 听到/看到真实回答，硬件小屏反馈状态，历史与轨迹可查 | 区分无有效语音、上游报错、工具失败与掉线，脱敏显示，不伪报成功 |
| 授权操控个人电脑 | 本地启动 `desktop_node` 连入云端/本机，口头或文字下达任务，确认首步操作后自动连续执行，或随时喊“停止/关闭” | 看屏（SoM+UI 树）并精准完成点击、输入与核验；喊停时立即终止任务并隐藏桌端提示条 | 权限缺失明确报 `screen_capture_denied` / `accessibility_denied`；连续 3 轮全错熔断止损 |
| 管理配置与回看记录 | 免登录进入网页调整模型/人设/能力/知识库、检查电脑与硬件状态、查看对话历史与 Agent 轨迹 | 配置保存立即作用于后续轮次且不清空历史；可按会话查看完整对话与逐轮轨迹 | 保存失败保留输入；公网不暴露桌端令牌与截屏预览；删除失败不伪报成功 |

## R02 运行方式、模型与联网

- Windows/Mac 开发测试，2 核约 1.87GB 云端独立长期承载；正式交付后不依赖开发机常开（仅被操控的个人电脑在需被操控时在线运行 `desktop_node`）。
- 实时语音与网页实时文字主线采用百炼 **`qwen-audio-3.1-realtime-flash`**，音色采用百炼 `voice-enrollment` 塔菲复刻音色（`AI_RT_VOICE`）；仍兼容 OpenAI Realtime 及显式分模型 Pipeline（LLM / ASR / TTS）切换。
- 联网搜索采用百炼内置 `enable_search`（开启 `search_options.enable_source`），并**将天气查询合并入内置联网搜索**：启用后不再单独暴露 `web_search` 与 `get_weather` 函数工具、不再提供独立「天气查询」卡片与默认城市设置；用户未说明城市时由模型主动追问。
- 电脑操控（Computer Use）支持百炼原生视觉模型（`qwen3.8-max-0902`、`qwen3.5-plus`、`qwen3.5-flash` 等），默认开启 `enable_thinking: False` 以降低每步延时，并在模型卡片内置「测试」连通性验证入口。

## R03 唤醒与按键入口

硬件端沿用现有“塔菲”语音唤醒与正面屏幕按键；不同固件状态与按键语义按已验证行为核对，不擅自刷写新固件、改动板级引脚或自动把未验收实验动画合入线上发布。

## R04 会话、上下文与记录

- 待机唤醒/按键开启新硬件对话段，段内多轮共享上下文，与网页文字会话彼此独立。
- 完整文字历史持久化存库，活跃上下文按最近 6 轮 / 6000 字符裁剪并允许工具按需检索当前会话旧原文，绝不把全库历史塞入每次请求、绝不在保存设置时清空历史。
- 回复消息「详情」面板展示真实模型、来源、**等待耗时（`first_response_ms`）**与 Token 消费明细；**不展示估算费用**与冗长解释段落。

## R05 结束方式与音频隐私

- 保持回答播完后 30 秒静默自动结束、明确结束意图（“不聊了/再见/关闭/退下”等）结束、活动中正面按键结束三种待机路径。引用结束词不误触。
- 不长期保存对话录音，不提供历史录音回放；必要音频缓冲在完成、失败、取消或断连后释放。

## R06 语音与网页实时打断（含电脑操控即时停止）

- 对话播放期间用户直接开口（VAD）停止旧播放与缓存并衔接新输入；新输入前缀尽量保留，旧轮迟到音频不回灌。
- **跨通道即时打断电脑操控**：无论当前是语音（AtomS3R / 网页）还是网页文字正在执行桌面操作或其它长耗时工具，用户随时说“停止/别动/别动了/住手/stop/关闭”或点击网页「停止」按钮时，服务端必须在当前轮次之外也能跨会话立即取消在途任务、撤回所有 3 分钟桌面租约，并向所有在线 `desktop_node` 广播 `abort` 指令（立即隐藏悬浮 HUD 边框并终止在途 RPC），确保电脑瞬间停手。

## R07 失败与重连

- 空语音/纯噪声不提交模型；上游报错脱敏后在对话和「记录 → 异常」可见。
- 网络短断按已鉴权设备重连回未结束段，已结束或服务重启后不重播旧回答、不重提上游付费请求。

## R08 双环境与首声目标

- 安静桌面近距离及客厅约 1–2 米有背景音均为硬件唤醒与对话的目标环境，目标首声延时约 3 秒内。新实时模型在真机上的实际首声与复杂背景打断听感须通过实机测试记录后再做结论。

## R09 网页工作台与管理边界

- 按用户决定保持免登录访问（仅限个人工作台）；保留 HTTPS/WSS、独立设备凭据、内部代理凭据校验与写操作同源检查，前端绝不获取真实模型 API Key。
- **设置分组清晰极简**：
  - 「模型」页仅保留「日常对话与语音」「电脑操控模型」两张卡片及折叠「高级设置」（仅保留 `人声灵敏度阈值`、`按需发工具`、`工具等待播报首响` 3 个可调项）。
  - 「联网搜索」卡片精简为开关 + `测试` 按钮与通断状态指示。
  - 「设备 → 电脑」在公网访问时优先展示在线/离线电脑卡片（基于 `/health` 只读 `desktop_nodes`，不含配对令牌与截屏），并将「接入新电脑」2 步可复制终端指令（不含尖括号占位符）默认折叠；真实配对令牌管理与截屏预览仅对本机回环开放。
- **「记录」四页签重构**：
  - **对话历史**：列表 1:1 对齐侧栏「最近对话」会话，点击「详情」进入**左树右详「Agent 执行轨迹」分栏视图**（左侧按用户轮次/步骤展示模型与工具调用树并标出耗时，右侧展示每一步的输入、输出与 Token/等待耗时明细）。
  - **知识库**：仅显示纯检索（`kb_only=true`）记录，不与普通对话混杂。
  - **工具调用**：展示各工具调用明细、耗时与状态。
  - **异常**：展示系统脱敏异常日志（`system_errors`），支持分页筛选与清空。

## R10–R13 历史容量、每日备份与设备恢复约束

- **长期历史（R10）**：在线文字历史无限期保留，仅用户可删除；数据库分页与容量保护防止页面卡死。
- **每日独立备份（R12）**：每天 1 次 SQLite 热备并向独立目标保存 30 天副本且经一次实际恢复核对，目前待在云端完成异地存储与 cron 配置。
- **设备恢复约束（R13）**：AtomS3R 已接通自有云端 OTA 与 WSS；原平台恢复仅作应急留底，不猜默认地址、不擅自修改 OTA 或串口盲操。
